# 🎉 „Wer weiß denn sowas, Horst?" – Spielshow zum 70. Geburtstag

Komplettpaket für eine kurze „Wer weiß denn sowas?"-Show auf der Geburtstagsfeier.

| Datei | Inhalt |
|---|---|
| `ablaufplan.md` | Spielprinzip, Ablaufplan am Festtag, komplette Checkliste, Moderations-Spickzettel |
| `fragenkatalog.md` | Alle Fragen mit Antworten & Erklärungen, Reservefragen, 10 Vorlagen für persönliche Horst-Fragen, Finale-Ideen |
| `spielbrett.html` | **Die interaktive Spieltafel** – im Browser öffnen, an TV/Beamer anschließen, losspielen (läuft komplett offline) |
| `abc-karten.html` | A/B/C-Antwortkarten zum Ausdrucken (2 Sätze) |

## Schnellstart

1. `spielbrett.html` doppelklicken → öffnet sich im Browser, `F11` für Vollbild.
2. Kategorie anklicken → Frage mit A/B/C erscheint → „Auflösen" → Punkte vergeben → zurück zur Tafel.
3. Vor der Feier: die `[AUSFÜLLEN]`-Stellen in `spielbrett.html` (Kategorie „Horst
   persönlich" und Finale) mit einem Texteditor durch eure echten Antworten ersetzen.
   Vorlagen und Ideen dafür stehen im `fragenkatalog.md`.
4. Checkliste im `ablaufplan.md` abarbeiten – fertig ist die Show. 🎬
